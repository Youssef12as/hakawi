# 🎨 واجهة حكاوي الأمامية (Frontend Architecture & Technical Roadmap)

هذا الملف يمثل **دليل الفريق البرمجي** لتطوير الواجهة الأمامية لمشروع "حكاوي".
تم تصميم الواجهة بنظام **Single Page Application (SPA)** مبسط باستخدام Vanilla JS، لضمان السرعة والاحترافية.

---

## 🏗️ الهيكل الأساسي (The App Shell)
التطبيق يحتوي على **شريط تنقل جانبي (Global Sidebar)** يتحكم في إظهار وإخفاء **3 تبويبات رئيسية**.

1. **الخريطة (`#view-map`):** الشاشة الرئيسية التفاعلية.
2. **شخصياتي (`#view-family`):** لإضافة شخصيات الأجداد.
3. **حكايات أطفال (`#view-kids`):** لتوليد قصص بصوت الشخصيات.

---

## 💡 الخيارات التقنية المتاحة (Technical Options Roadmap)
لكل جزء في التطبيق، هذه هي الخيارات التقنية المتاحة للتنفيذ (من الأسهل للأكثر احترافية):

### 1️⃣ خريطة التراث (Interactive Map) 🗺️
هي الواجهة الأولى التي يفتح عليها التطبيق.

- **الخيار الأول: SVG Interactive Map (الوضع الحالي - الأنسب للهاكاثون) 🎨**
  - **الوصف:** صورة SVG مرسومة لمصر مع نقاط مضيئة مبرمجة بـ CSS.
  - **المميزات:** خفيفة جداً، شكلها تراثي/فني، لا تحتاج API Keys أو إنترنت.
- **الخيار الثاني: Leaflet.js + GeoJSON ⚡**
  - **الوصف:** مكتبة خرائط مفتوحة المصدر.
  - **المميزات:** تسمح بالـ Zoom الدقيق وإضافة الـ Markers بسهولة.
- **الخيار الثالث: Mapbox GL JS ✨**
  - **الوصف:** منصة خرائط احترافية 3D.
  - **المميزات:** تضاريس ثلاثية الأبعاد خرافية، لكن تحتاج إنترنت وحساب API.

### 2️⃣ واجهة المحادثة (The Chat Page) 💬
تفتح عند اختيار شخصية من الخريطة.

- **الخيار الأول: Vanilla JS & CSS (الوضع الحالي) ⚡**
  - **المميزات:** مبنية من الصفر، سريعة، ولا تحتاج بيئة Node.js.
- **الخيار الثاني: React.js + Tailwind CSS ⚛️**
  - **المميزات:** ممتازة إذا كانت الحالة (State Management) ستصبح معقدة جداً مع الصوت والصورة.
- **الخيار الثالث: Chat UI Libraries (مثل Chatscope) 📦**
  - **المميزات:** توفر واجهة جاهزة فوراً، لكن تخصيص تصميمها التراثي قد يكون صعباً.

### 3️⃣ المُعلم التفاعلي والـ 3D (Interactive Mentor / 3D Avatar) 🧊
الجزء الخاص بالتفاعل البصري مع الحرف أو رؤية الشخصية التراثية.

- **الخيار الأول: Spline (Spline.design) (السحري للهاكاثونات) 🪄**
  - **الوصف:** أداة تصميم 3D تُصدر المشهد كـ `<script>`.
  - **المميزات:** مشاهد 3D مبهرة (خيمة، معبد) تتحرك بالماوس، تُنفذ في 10 دقائق بدون كود معقد.
- **الخيار الثاني: Vision LLMs (API) 📷**
  - **الوصف:** رفع صورة للحرفة اليدوية إلى Gemini/GPT-4V ليقوم بتحليلها واستخراج نصائح.
  - **المميزات:** صفر تدريب، دقة خرافية في الفهم، ويسهل دمج الرد مع الـ TTS.
- **الخيار الثالث: Teachable Machine + Canvas 🧠**
  - **الوصف:** تدريب نموذج خفيف على متصفحك للتعرف على حركات اليد.
  - **المميزات:** مبهر جداً كـ Live Demo للكاميرا، لكنه يحتاج لظروف إضاءة ثابتة.
- **الخيار الرابع: ReadyPlayerMe أو Three.js 👤**
  - **الوصف:** شخصيات 3D حقيقية تحرك شفايفها (Lip-sync).
  - **المميزات:** واقعية شديدة، لكنها معقدة برمجياً وقد تستهلك كل وقت الهاكاثون.

## 🛠️ كيف تبدأ العمل؟
- افتح `index.html` ستجد الأقسام مقسمة بـ `id="view-..."`.
- لتسهيل العمل، قم بتغيير كلاس `hidden` إلى `active` في القسم الذي تبرمجه ليظل ظاهراً أمامك.
- دوال التنقل موجودة في `script.js` باسم `switchView(id)`.
